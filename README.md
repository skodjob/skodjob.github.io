# skodjob.io

This repository contains blog posts that are published automatically to our [blog](https://skodjob.io).

## Running locally

To preview the blog locally during development:

1. Install dependencies:
   ```bash
   cd docs
   bundle install
   ```

2. Start the local server:
   ```bash
   bundle exec jekyll serve
   ```

3. Open your browser to [http://localhost:4000](http://localhost:4000)

The site will automatically reload when you make changes to posts or other files.
